# Adiology-V-1

Welcome to Adiology-V-1! This repository is set up to make it easy to upload and organize your files.

## Quick Start: Upload Files

### Method 1: Git Command Line
```bash
# Clone the repository
git clone https://github.com/samayhuf-star/Adiology-V-1.git
cd Adiology-V-1

# Add your files
cp /path/to/your/files/* .

# Commit and push
git add .
git commit -m "Add my files"
git push origin main
```

### Method 2: GitHub Web Interface
1. Go to https://github.com/samayhuf-star/Adiology-V-1
2. Click "Add file" → "Upload files"
3. Drag and drop your files
4. Commit your changes

### Method 3: GitHub Desktop
1. Install [GitHub Desktop](https://desktop.github.com/)
2. Clone this repository
3. Copy files to the local folder
4. Commit and push
